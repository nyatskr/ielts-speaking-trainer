Three systems · built end to end

Language tools that explain themselves.

I build small, complete systems around language learning. One turns written scripts into an audio trainer you can click through sentence by sentence. A second reuses those same timings to check a dictation word by word. A third scores an IELTS essay against the official band descriptors and shows where every mark was lost. All three run entirely in the browser, with no backend.

02 / Approach

Three rules I kept

Rule 01

Heavy work happens offline

Synthesis, chunking and forced alignment run in Python before anything is published. The site itself only reads files, so a two-hour build becomes a page that opens instantly.

Rule 02

No backend unless it earns one

All three are static files on GitHub Pages. Progress, drafts and API keys live in localStorage. Nothing to deploy, nothing to keep awake, nothing to leak.

Rule 03

Every score needs evidence

A band number on its own teaches nothing. Each judgement is tied to a named criterion and to a specific sentence the learner can go back and change.
